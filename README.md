## Run
This is a static website. The easiest method is to open `index.html` in a browser.

For a local development server:
1. Open this folder in VS Code.
2. Open a terminal.
3. Run one of:
   - `python -m http.server 8000`
   - or use the VS Code Live Server extension.
4. Visit `http://localhost:8000`

## Important data note
The supplied report says measurements are indicative because low-cost instruments were used for short-duration readings. It also contains a note that the listed site names are sample entries and should be replaced with actual visited locations if needed. The website preserves that caveat rather than presenting the readings as regulatory-grade data.
